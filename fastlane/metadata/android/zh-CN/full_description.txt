LogSleuth 是一个安卓日志工具,包含两种模式。

查看器 App:精致的实时 logcat 查看器,支持级别着色、过滤(级别/Tag/关键字/正则/排除)、
保存过滤器预设、按应用过滤(Shizuku 或 Root)、后台录制会话、崩溃与 ANR 侦测通知、
悬浮书签气泡,以及导出 txt/zip(附设备信息)。

内嵌 SDK:开发者把 logsleuth-sdk 集成进自己的应用,即可零权限、零网络地记录该应用的
日志、崩溃与 ANR,用户两下点击即可把日志 zip 分享给开发者。

读取其他应用的日志需要一次授权。Shizuku 不需要 Root(Android 11+ 可在手机上通过无线调试激活)。
设备上已有 Magisk、KernelSU 或 APatch 时也可以用 Root,不打开就不会去要权限。
或者执行一次 ADB 命令:adb shell pm grant io.github.shiaho777.logsleuth.app android.permission.READ_LOGS。
Android 13 及以后,这条授权只在 LogSleuth 处于前台时才会开始读日志;Shizuku 和 Root 仍可在后台工作。
内嵌 SDK 模式则完全不需要授权。

开源(Apache-2.0),无广告、无跟踪。网络只用来检查 GitHub 上的更新。
